## Technical Information

### Frontend Dependencies
- `nuxt` - Framework fürs Frontend.
- `nuxt-ui` - UI-Komponente
- `vue` - UI-Basis43454
- `zod` - Validierung der Eingaben(Frontend)

### Backend Dependencies
- `fastify` - Webserver für die API-Endpunkte.
- `sequelize` - ORM für Datenbankzugriffe und Models.
- `sqlite3` - Die Datenbank SQlite halt.
- `zod` - Serverseitige Schema Validierung.

## Setup

### Frontend
```bash
cd frontend
npm install
npm run dev
```

### Backend
```bash
cd backend
npm install
npm run dev
```
